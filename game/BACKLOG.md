# 待辦與想法

這份清單記錄已經決定要做、但還沒排進去的東西。做完就從這裡移除。

## 你指定要記著的

- **換技能**：玩家可以更換自己帶的技能，而不是每個職業固定四招。
  - 待確認：每個職業的技能池要多大、是否保留「第三格固定是打斷」這個規則。
- **拖曳鎖定**：用拖曳的方式鎖定目標。
  - 目前的理解：從技能鍵拖曳出去指向某個敵人或隊友，放開就對他施放並鎖定為目標。這個理解還沒跟你確認過。
  - 現況：只能點戰場上的敵人換目標，治療可以點上方隊友血條指定對象。

- 招募板（用卡片找隊友，代替公開頻道）

- 材料和裝備能不能在玩家之間交易，還沒決定
- 更多任務；主線目前只有 8 個，做完就沒有了
- 每週任務的「休息累積」（幾天沒上線可以補回來）還沒做，現在只是單純每週重置
- 劇情：第一版草稿已寫（序章加 8 段，`story.js`），方向和呈現方式等你確認，選項見對話紀錄
- 野外：單人時在手機上運算，組隊時由伺服器運算
- 野外事件：走進範圍就無讀取加入，定時開放
