# 燼潮 Embertide

直立手機的三分鐘四人副本。可以單人玩（AI 隊友），也可以連線和其他玩家一起打。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 用戶端：畫面、操作、連線 |
| `sim.js` | 戰鬥運算，瀏覽器（單人）和伺服器（連線）共用同一份 |
| `server.js` | 連線伺服器：提供網頁、帳號、好友、房間配對、在伺服器上跑副本 |
| `story.js` | 劇情內容：序章、每個主線任務各一段短對話、營地角色的閒聊 |
| `art/` | 像素圖：`manifest.js` 登記誰有圖，`<id>/<動作>_<方向>.png` 是一條條的動畫格。規格在 `art/README.md`。沒登記的角色照舊畫幾何圖形 |
| `store.js` | 帳號存檔：記憶體加一個 JSON 檔，另外可以打包成有簽章的備份 |
| `editor.js` | 編輯器：在遊戲裡改數值、道具和地圖 |
| `data.js` | 正式的設定：和程式預設不同的數值，由編輯器存的內容寫入 |
| `tools/write-data.js` | 把編輯器存的內容寫進 `data.js` |
| `test/online.test.js` | 用模擬玩家測伺服器 |

## 在自己電腦上跑

需要 Node 18 以上。

```
cd game
npm install
npm start        # http://localhost:8080
npm test
```

同一個 Wi-Fi 下的手機開 `http://<電腦的區網 IP>:8080` 就能一起玩。

## 連線怎麼運作

- 副本在伺服器上算，用戶端只送操作（移動、放技能），伺服器每秒回傳 15 次畫面狀態。
- 自己的角色移動會先在本機顯示，再向伺服器的位置靠攏，所以拖曳不會有延遲感。
- 留空房號是隨機配對：8 秒內湊到的人一起出發，空位由 AI 補上。
- 輸入房號是和朋友開房：在場的人都按開始，或四人到齊就出發。
- 斷線時 AI 會接手你的角色；重新連上（包含重新整理頁面）會回到原本的位置。

## 角色

- 遊戲開啟後先到選角畫面；沒有角色時直接進創角畫面。創角要選職業、取名字（最多 8 個字）。
- 一個帳號最多 4 個角色。職業在創角時決定，之後不能改。
- 每個角色有自己的等級、經驗、塔的層數、裝備、背包、任務進度和技能配置。好友名單屬於帳號，所有角色共用。
- 別人看到的名字是你目前使用的角色名。
- 連線時角色存在伺服器；在房間或副本裡不能換角色。進副本的職業一律以角色為準，不看手機送來的資料。
- 刪除角色要按兩次確認，刪掉無法復原。
- 舊版（沒有角色的時候）的存檔會自動變成一個角色。

## 帳號和存檔

- 第一次連線時伺服器發一個帳號（之後在帳號底下創角色），登入用的金鑰存在這台裝置的瀏覽器裡。目前沒有綁定信箱，清掉瀏覽器資料或換裝置就是新帳號。
- 層數、裝備、通關紀錄、好友名單都存在伺服器。線上副本的掉寶和升層由伺服器決定。
- 單人副本在手機上運算，結束時回報伺服器。伺服器無法重演那一場，只檢查合不合理（層數不超過帳號層數、花的實際時間夠長）。
- 存檔寫在 `DATA_DIR`（預設 `game/data/`）。主機的硬碟如果不保留（免費方案常見），伺服器重啟後檔案會消失：
  這時裝置會交出伺服器簽過章的備份，伺服器驗章後還原。簽章用的 `EMBERTIDE_SECRET` 必須固定，換掉後舊備份全部失效。
- 備份只在本人上線時還原。硬碟不保留的主機重啟後，還沒上線的人不會出現在別人的好友狀態裡，要等他們回來。

## 背包和製作

- 副本掉三種材料：鏽鐵屑、鹽晶、沉鐘碎片。三分鐘內通關一定有沉鐘碎片，滅團也會拿到少量鏽鐵屑。
- 鍛造：直接做一件指定部位的裝備，裝等是該層的中上水準。比身上好就換上，換下來的進背包。
- 淬鍊：把身上某個部位的裝等加 2，上限跟著帳號層數走。
- 潮息藥水：副本中回復 35% 血量，每場限用 1 瓶，最多帶 5 瓶。
- 規則寫在 `sim.js`，伺服器和離線版用同一份。連線時背包以伺服器為準，製作由伺服器執行。

## 進塔和出塔

- 主選單只有「進入世界」。配對不在主選單做，在世界裡做。
- 沉鐘塔在 Lv.3 開放（`sim.js` 的 `TOWER_LEVEL`，伺服器也會擋）。新角色先在鏽灘打怪、採集、做任務；升到 Lv.3 時會提示，畫面上方的「副本」按鈕也會變色。
- 「副本」按鈕在野外任何地方都能按，打開找隊伍的面板：隨機配對、單人進塔（隊友是 AI）、和所在的隊伍一起進塔、用房號和朋友組隊，或用房號去朋友的野外。走到塔門按互動鍵，開的是同一個面板。
- 排隊不會把你帶離世界。左上多一條提示：「找隊友中　5 秒」或「房間 AB12　2/4 人」，旁邊是「開始／不等了」。點提示（或再按一次「副本」）打開隊伍面板：看誰到了、改分配方式、複製邀請連結、邀請好友、不排了。
- 隊伍湊齊（四人到齊、在場的人都按了開始，或隨機配對時間到）就直接進塔。伺服器會記下你被帶進去時站的位置。
- 伺服器上，「站在哪個世界」和「在等哪個隊伍」是分開記的，所以等的時候不會離開野外；「不排了」也只離開隊伍。
- 朋友給的邀請連結：打開後進入世界，會問你要去他們的野外，還是一起進塔。

### 打完之後

- 打贏不換畫面，塔也不會消失：計時停住、倒下的人站起來、塔頂出現傳送門，大家還能在裡面走動。
- 下方先出現一塊面板：時間、這場的數字、拿到的東西、要分的掉落（擲骰或隊長分配在這裡按）、隊友。按「收起」它會縮成左上的「戰利品」，可以再點開。
- 走到傳送門按「走進傳送門」，選「回到原本的位置」（被帶進塔時站的地方）或「到塔門口」。跟隊伍來的會回到隊伍的野外。
- 「再來一場」：單人直接重打；線上則是人留在塔裡重新排隊，同一場的隊友會收到「想原隊再打一場」的邀請。
- 打完的塔在伺服器上最多保留 2 分鐘，或到最後一個人離開為止。房號在打贏的當下就空出來，可以馬上用同一個房號再組一隊。
- 滅團時塔會結束，面板上是「再試一次」和「離開」（回到塔門口）。

## 角色面板

- 在野外，畫面左上「離開」旁邊有「角色」「副本」「任務」三個按鈕。「角色」點開就是角色面板，「任務」可以看進度和領支線、每週任務的獎勵（有可領的會顯示數字），都不用回主選單。
- 面板有四頁：裝備（穿著的三件、數值、套裝）、背包（材料、多的裝備、工坊）、天賦樹、技能書。
- 在野外改的東西當場生效：換裝備、點天賦、換技能之後，場上的角色馬上跟著變，技能鍵也會換。組隊野外由伺服器套用。
- 換技能時冷卻跟著格子走，不會因為換技能而重置。
- 副本裡沒有這個按鈕：三分鐘的戰鬥中不能換裝備、天賦和技能。

### 在野外開的面板

- 在野外打開的面板（角色、商人、信箱、拍賣）不會蓋掉整個畫面：它是下方約六成高的面板，上面是半透明的暗色遮罩，世界照常運作、看得見。
- 面板打開時鏡頭會把你的角色往上移到遮罩那一塊的中間；在地圖南緣（營地）鏡頭可以多捲一點，角色才不會被面板擋住。
- 被打的時候，面板上緣會跳出紅色警示，顯示目前生命；點警示或點上面的世界都會關掉面板。
- 主選單上開的同一批面板仍然是整頁，因為後面沒有世界要看。

## 裝備、掉落和套裝

- 裝備是一件一件的物品：有部位（武器、護甲、飾品）、裝等、品質（普通、精良、稀有）和名字。身上穿三件，其餘放背包，背包最多 16 件。
- 拿到比身上好的會自動換上，換下來的進背包。背包滿了，放不下的那件直接照商人的價格賣掉。也可以在背包裡手動換。
- 掉落來源：塔裡的小怪每隻有一成機率掉一件；莫葛一定掉；鏽灘的野怪偶爾掉（約 5%）；撐過漲潮有四成機率多拿一件。機率都在 `sim.js` 的 `DROP` 和 `TRASH_DROP`。
- 單人進塔（隊友是 AI）：掉的全部歸你。
- 兩個真人以上：掉落集中成一堆，打完在結算畫面分。莫葛掉的件數看人數（2 到 3 人掉 2 件，4 人掉 3 件）。
  - 擲骰：每件各自選「需求」「貪婪」「放棄」。有人需求就只比需求的人，點數 1 到 100 高的拿走。只有比身上好的才能按需求。時間到沒按算放棄。
  - 隊長分配：開房間的人是隊長（他離開就換下一位），可以在房間畫面把分配方式改成隊長分配，打完由他指定每件給誰。時間到還沒分的，在場的人擲骰。
  - 隨機配對的隊伍一律擲骰。
  - 材料、經驗、鐘幣每個人各拿各的，不用分。野外的掉落也是各拿各的。
- 套裝：有三套（看守者、霧燈、潮鳴），每套三件。穿兩件有第一個加成，三件再多一個。內容在 `sim.js` 的 `SETS`。
  - 身上那件屬於已經生效的套裝時，撿到裝等更高的散件不會自動換上，避免套裝被拆掉。
- 鍛造做出來的也是一件物品（工坊武器、工坊護甲、工坊飾品）。淬鍊加在身上那一件上，跟著那件走。
- 多的裝備可以在營地找老錨賣掉。

## 鐘幣、商人和天賦

- 鐘幣：通關、任務、漲潮、野怪偶爾會給。用來向商人買東西、重置天賦。
- 商人老錨站在營地，走過去按互動鍵。賣藥水和基本材料，收材料和裝備。價格在 `sim.js` 的 `SHOP`。
- 天賦：每升一級得一點，每個職業 9 個天賦分三排，下一排要先投滿一定點數。重置要花鐘幣。內容在 `sim.js` 的 `TALENTS`。
- 仇恨顯示：選中敵人時畫面上有仇恨表，列出每個人相對最高仇恨的比例；怪正在打誰，那個人的血條會有標記；你快要搶到仇恨時會警告。

## 信箱

- 需要伺服器。主選單的「信箱」和營地的信箱都能開，有未讀會顯示數字。
- 只能寄給互相加了好友的人（名字不是唯一的，所以不能靠名字寄給陌生人）。
- 一封信可以寫 80 個字，附鐘幣、一種材料、一件背包裡的裝備。郵資 5 鐘幣。
- 信屬於帳號；附件從寄信當下使用的角色身上扣，由收信人領取當下使用的角色收下。
- 信箱上限 30 封。信裡還有東西時不能刪。拍賣場寄來的信不受上限影響。

## 拍賣場

- 需要伺服器。在營地找秤婆。
- 只有一口價，沒有競標：賣家標價，第一個付錢的人買走。可以賣背包裡的裝備或材料（穿著的要先換下來）。
- 上架時東西就離開背包。賣出後抽 5%，錢用信寄給賣家。24 小時沒賣掉，或自己下架，東西用信退回。
- 一個帳號同時最多上架 8 樣。買裝備時背包要有空位。
- 這些數字在 `server.js` 最上面：`MAIL_CAP`、`MAIL_FEE`、`AH_MAX`、`AH_CUT`、`AH_HOURS`。
- 上架中的東西存在賣家的帳號裡。硬碟不保留的主機重啟後，賣家重新上線前，他的東西不會出現在拍賣場。
- 已知限制：在硬碟不保留的主機上，帳號是靠各自裝置上的備份還原的，跨帳號的轉移（信件、拍賣）在重啟前後可能對不上，例如賣家用賣出前的舊備份還原，東西會回到他手上。正式營運要用會保留的硬碟或資料庫。

## 編輯器：改數值、道具和地圖

選角畫面和主選單都有「編輯器」按鈕。它是照手機寬度做的：清單點進去是表單，地圖用手指拖。

**可以改的**

| 分頁 | 可以改 | 可以新增／刪除 |
| --- | --- | --- |
| 規則 | 等級上限、經驗曲線、每級強度、背包格數、藥水、重生時間、掉裝機率 | |
| 職業 | 名字、生命、攻擊、攻速、距離、速度、仇恨、大招充能 | |
| 技能 | 名字、說明、冷卻、解鎖等級、距離、範圍、攻擊倍率、治療和護盾量、持續和暈眩秒數 | |
| 天賦 | 名字、說明、第幾排、最多幾點、加成種類和數值 | 可以 |
| 怪物 | 名字、生命、傷害、攻速、速度、警戒和追擊距離、經驗；王的招式 | 複製現有的怪成為新怪物；王的招式可增減 |
| 副本 | 名字、開放等級、限時；波次型的每一波；漲潮的三波 | 新增波次型或場景型副本、增減波數 |
| 副本場景 | 場景型副本的大小、入口、地形、怪、王、稀有精英、寶箱、事件；怪的巡邏方式 | 都可以新增刪除 |
| 掉落 | 各種掉裝機率、掉的是套裝的機率 | |
| 套裝 | 名字、三件的名字、兩件和三件的加成 | 可以 |
| 裝備名 | 不屬於套裝的裝備名字 | 可以 |
| 商人 | 賣什麼、收什麼、價格 | 填 0 就是不賣／不收 |
| 配方 | 每樣東西要花的材料 | |
| 任務 | 標題、目標文字、需要的次數、獎勵 | 可以新增刪除六種任務，並串成任務鏈（見下面「自己做任務」） |
| 地圖 | 每張地圖的名字和大小；怪群、採集點、岩石、牆、水、路、出入口、出生點、副本入口的位置；鏽灘另有漲潮點、營地的人、攤位 | 新增地圖；怪群、採集點、岩石、牆／水／路、出入口、副本入口 |

**還不能在編輯器裡做的**（行為寫在程式裡）：新的技能、新的怪物行為和新的招式積木、新的任務類型、新的材料、新的配方種類、營地的位置。要加這些跟 Claude 說。

**怪物、王、副本、地圖怎麼組合**

- 怪物的行為由「原型」決定，共六種：塔裡的近戰怪、塔裡的施法怪、王、野外的近戰怪、野外的施法怪、野外的精英。新怪物是把現有的複製一份，再改名字和數值；原型不能改。塔的原型只能放進副本，野外的原型只能放進地圖的怪群。
- 王的行為是一串招式積木，由上往下，先準備好的先放：
  - 扇形斬：朝目標砍出扇形，有預警。
  - 落點圈：在幾個人腳下放圈。
  - 震盪：以王為中心的大圈，要跑開。
  - 全場吼叫：金色讀條，沒打斷就全隊受傷。
  - 召喚小怪：血量低於某個比例時叫出幾隻。
  - 狂暴：血量低於某個比例後動作變快。
  每個積木有自己的時間、傷害和範圍。原本的莫葛就是用這幾塊組出來的。
- 副本有兩種，每個都有名字、開放等級和限時（在限時內通關才升層）。每個角色在每個副本各有自己的層數，互不影響。「副本」面板會列出所有副本讓玩家選。
  - **波次型**：一個固定的場地，一到八波怪依序出現，打完最後一波通關。沉鐘塔是這一種。
  - **場景型**：像編輯場景一樣自己擺出來。在「副本」分頁按「編輯場景」，會進到和地圖同一個編輯畫面：
    - 怪：一組一到四隻。玩家靠近或打到牠才開戰，同一組一起上。平常可以站著不動、在一個範圍內遊走，或照路線巡邏。路線最多六個點，地圖上是連著線、有編號的小圓點，可以直接拖、可以加點刪點；走到最後一點後可以選原路走回來，或直接走回起點繞圈。拖動怪本身時，整條路線會跟著移動。
    - 王：選王型的怪就是王。場景裡所有的王都倒下就通關；沒有放王的話，清光所有怪通關。王加入戰鬥時才會出現王的血條。
    - 稀有精英：比一般的硬 2.5 倍、痛 1.3 倍，倒下必掉一件裝備。
    - 出現機率：怪和寶箱都能設，每次進副本重新決定在不在。稀有精英和寶箱通常設小於 1。
    - 寶箱：玩家走到旁邊（不在戰鬥中）就打開，多一件裝備進這一場的掉落。
    - 事件：玩家走進範圍觸發一次。目前三種：伏擊（冒出幾隻怪）、旁白（畫面上出現一行字）、回復泉（全隊補滿、倒下的站起來）。
    - 地形：岩石、牆、水、路，和地圖一樣。
    - 入口：隊伍進副本時出現的位置。
  - 場景型副本裡，鏡頭會跟著你捲動，有小地圖。打完一場戰鬥後會自己回血，倒下的隊友會站起來。AI 隊友會跟著玩家走，只打已經開戰的怪；牠們不會繞牆，落後太遠會直接跟上來。
  - 通關後傳送門開在最後一隻王倒下的地方。
- 地圖可以開新的，設定名字和大小。地圖之間用出入口相連，出入口是單向的，要能走回來就兩邊各放一個。牆和水會擋路，路只是顏色。每張地圖有一個出生點，倒下後在那裡站起來；可以放一個副本入口。
- 野外的怪群可以取自己的名字、設巡邏路線（最多六個點，來回或繞圈）、設自己的重生秒數。取了名字的怪名牌是金色的。巡邏中的怪被拉走後，會回到被拉走的位置再繼續走，不是回最初的地點。
- 「擊倒指定的怪」任務：在「任務」分頁新增，目標從所有取了名字的怪裡選，可以設次數和獎勵。只有打倒那隻有名字的怪才算，同種類的其他怪不算。這就是「追殺路上巡邏的信使」那種任務。這類任務放在支線，在野外畫面上方的「任務」按鈕裡領獎。

### 自己做任務

在編輯器「任務」分頁按「新增任務」，選類型：

| 類型 | 怎麼算一次 | 要先準備什麼 |
|---|---|---|
| 擊倒一隻有名字的怪 | 打倒那一隻（同種類的其他怪不算） | 在地圖上替一組怪群取名字 |
| 擊倒某一種怪 | 打倒那一種野怪；可以限定在某張地圖 | 無 |
| 採集 | 採到一次；可以限定採哪一種、在哪張地圖 | 無 |
| 收集任務物品 | 打倒指定的怪（某一種，或有名字的那一隻）時照機率掉一個 | 無 |
| 到達一個地標 | 走進地標的圈裡 | 在地圖上用「＋地標」放一個、取名字 |
| 通關副本 | 通關一次；可以指定哪個副本、要不要在時限內 | 無 |

- 任務鏈：每個自訂任務有「什麼時候出現」，可以選「交完某個任務之後」。前一個沒領獎之前，後一個不會出現，也不會偷偷累積進度。
- 任務物品不佔背包，只是任務上的計數；掉到的時候頭上會跳「物品名 1/3」。
- 地標：野外地圖上的一個圈和名字。走進去畫面會出現「發現　地標名」，小地圖上是一個小黃點。每張地圖最多 10 個，名字不能重複。
- 目標文字會跟著你選的內容自動寫（例如「從鏽灘蟹身上收集蟹殼」）；自己改過之後就不再自動改。
- 擊倒、採集、物品這幾種目前只算野外的怪，副本裡的怪不算。
- 還沒有的：和營地的人對話交任務、護送。
- 營地、營地的人、攤位和漲潮事件只在鏽灘。新地圖沒有安全區。
- 組隊時，同一隊的人在不同地圖會各在各的野外，走到同一張地圖才會碰面。
- 刪掉一種怪物、一個副本或一張地圖時，用到它的怪群、波次、招式和出入口會一起被拿掉。

**怎麼運作**

- 每改一格，規則會當場檢查：超出範圍的數字會被拉回，名字重複或格式不對的那一筆不會被加入，畫面上會提示。
- 改動立刻套用，並存在這台裝置上。按「關掉去試玩」進遊戲就是新的數值，重新整理也還在。和原本不同的欄位會用金色標出來並顯示預設值。
- 「全部還原成原本的設定」會清掉這台裝置上的改動。
- 這些改動只在沒有伺服器的單機試玩生效。連上伺服器時，頁面會改用伺服器上的設定，因為規則是伺服器在算。
- 要讓改動變成遊戲的正式設定：按「存到雲端」，再跟 Claude 說一聲，它會把內容寫進 `game/data.js`，伺服器和所有人都會用到。沒有雲端的版本（自己架的伺服器）會改成複製一段文字。
- 「讀雲端」可以把雲端上的那份載回來，例如在手機上改、到電腦上接著改。

**檔案**

- `game/data.js`：正式的設定，只記和程式預設不同的部分。伺服器啟動時套用，頁面在 `sim.js` 之前載入。
- `game/tools/write-data.js`：把編輯器存的內容寫進 `data.js`（`node tools/write-data.js saved.json`；`--reset` 回到預設）。
- `sim.js` 的 `exportData()`、`applyData()`、`LIM`：資料的匯出、套用，以及每個欄位的名稱和範圍。編輯器和檢查用的是同一份 `LIM`。
- 程式裡的預設值仍然在 `sim.js`（`TUNE`、`SKILLS`、`CLASSES`、`ENEMY`、`TALENTS`、`FIELD`、`DROP`、`SETS`、`SHOP`、`RECIPES`、任務）和 `story.js`（劇情）；郵資、拍賣抽成和時限在 `server.js` 最上面，還沒進編輯器。

## 技能和瞄準

- 每個職業有 6 個一般技能和 2 個大招，一次帶 3 個一般技能加 1 個大招。起始的 4 個以外，其餘在 3、5、8、10 級解鎖。資料在 `sim.js` 的 `SKILLS` 和 `CLASSES`。
- 換技能在角色面板的「技能書」。連線時由伺服器保存和檢查（要是該職業的、不重複、已解鎖）；沒有固定哪一格必須是打斷。
- 每個技能有一種瞄準方式：不用瞄準、選敵人、選隊友、選地上的位置、選方向（直線或扇形）。
- 短按技能鍵：自動施放。對敵人的技能會打目前鎖定的目標，沒有就找範圍內最近的；方向技朝目標放；位置技放在目標腳下；隊友技給最需要的人。
- 按住技能鍵拖曳：出現指示（直線、扇形、圓圈，或被選中的人身上的圈），放開就照指的地方施放。拖曳選到的敵人會成為鎖定目標。拖到上方的取消區放開則不施放。
- 瞄準資料跟著施放指令送到伺服器，伺服器只接受格式正確的方向、位置或目標，其餘當作短按處理。
- AI 隊友只會用起始的技能。玩家斷線被 AI 接手時，AI 只用它認得的那幾招。

## 等級

- 角色等級（Lv.1 到 30）靠經驗值升，和塔的層數是兩回事。升級會補滿血，並提高血量和傷害（每級約 6%）。
- 經驗來源：野外擊倒野怪、採集、通關副本（層數越高越多，準時再加兩成五）、領任務獎勵。滅團也有少量經驗。
- 野怪等級會跟著你浮動，但每一群有下限和上限（定義在 `FIELD.packs` 的 `min` 和 `max`）。南邊靠營地的最低，北邊靠塔門的最高，目前整張圖最高到 14 級。
- 野怪比你低 3 級以上，經驗開始遞減，低 7 級以上只剩一成；比你高則略多，最多三成。
- 玩家和野怪用同一條等級強度曲線，所以同等級的戰鬥在任何等級手感都接近，差距來自裝備。
- 副本的敵人和 AI 隊友顯示的是那一層的建議等級（第 N 層是 2N−1 級），副本實際強度仍然照層數計算。
- 連線時經驗由伺服器計算：野怪等級由伺服器依帳號等級和牠所屬的那一群算出來，手機只回報打倒了哪一群的哪一種。

## 野外

- 地圖「鏽灘」：營地在南邊，沉鐘塔的門在北邊，中間有野怪、採集點和岩石。地圖資料在 `sim.js` 的 `FIELD`。
- 一個人去野外時在手機上運算。野怪只會打主動招惹牠或走進牠範圍的人，追太遠會放棄並回原位；營地那一圈牠們不會進來。
- 採集：站在採集點旁邊不動就會自動採，被野怪追的時候不能採。
- 倒下 3 秒後在營火邊醒來，沒有懲罰。離開戰鬥一陣子會自己回血。
- 單人在野外時坦克和治療的傷害有加成，三個職業都打得動。
- 連線時每次採集和擊倒都回報伺服器，由伺服器決定給什麼，並限制速度：同一個點要等它長回來、採集不能比採集時間快、擊倒有固定的速率上限。
- 潮草只有野外有，藥水需要它。
- 營地的四個人可以對話。主線任務完成後要回營地找對應的人領獎，劇情就在世界裡播出來。
- 走到塔門可以直接進副本（單人或線上配對），打完可以選回營地。
- 還沒做：主城。

### 野外事件：漲潮

- 鏽灘上定時出現的公開事件。預設每 6 分鐘一次，每次開放 4 分鐘，地點在兩個位置之間輪流（`FIELD.events`）。
- 開放時地圖和小地圖上會標出範圍和剩餘時間；開始前一分半會先顯示倒數。
- 走進範圍就加入，不用按任何東西、不換畫面：手機會連到伺服器上這一次漲潮的共用場地，你出現在你走進來的位置。其他走進來的玩家（包含陌生人）都在同一個場地，最多 8 人。
- 內容是三波：螃蟹、螃蟹加學徒、精英「鏽錨巨蟹」（會砸地，有紅圈預警）。怪物數量和血量看當下在場人數，等級跟在場者的平均等級（限制在 3 到 16 級之間）。
- 事件中倒下會在事件邊緣站起來，不會被送回營地。
- 打完三波，在場的每個人都拿到經驗和材料（含一個沉鐘碎片）；時間到沒打完就什麼都沒有。
- 結束後會列出一起打的人，他們會出現在好友頁的「最近隊友」，可以加好友。這是野外認識陌生人的途徑。
- 走出範圍太遠會離開事件，回到你原本的野外（自己的或隊伍的），站在原地。
- 從隊伍的野外走進去時，是你一個人過去；隊友要各自走進來。
- 需要伺服器：沒有伺服器的版本不會出現事件。排程用伺服器的時鐘，`eventPeriod` 和 `eventDur` 可以在啟動時調整。

### 組隊野外

- 用房號組成隊伍一起去野外，最多 4 人，職業不限。野外裡只有同隊伍的人，沒有陌生人。
- 組隊的野外由伺服器運算，和副本用同一套連線方式；隨時可以用房號走進去或離開，不用等人、沒有準備畫面。
- 進入方式：主頁填房號後按「和隊伍去野外」，或從好友名單按「去野外」（會開一個新隊伍並邀請對方）。
- 野怪等級跟著隊伍的平均等級（仍在每一群的上下限內），血量隨人數增加，攻擊力不變。
- 採集點每個人各採各的：你採過的點只對你消失，隊友還看得到。
- 打倒野怪時，附近的隊友每個人都拿到經驗和掉落，各自計算。
- 一個人打野外時坦克和治療的傷害加成，在組隊時不適用。
- 走到塔門可以選「和隊伍一起進塔」：會用同一組房號開副本房間，其他還在野外的隊友會收到通知。副本有職業位置限制（一坦、一補、兩輸出），撞職業的人進不去。
- 斷線重連後會自動走回隊伍的野外。

## 任務

- 主線：一次一個、照順序，目前 8 個，帶玩家走過通關、打斷、製作、準時、淬鍊和爬層。
- 每週：四個（其中「撐過 2 次漲潮」需要伺服器），每週一 00:00（台北時間）重置。
- 支線：做一次就結束，順序不限，其中兩個在野外完成（採集、擊倒野怪）。需要其他玩家的支線在離線版不會出現。
- 進度在這幾種時候前進：打完一場副本、製作成功、互加好友、野外採集、野外擊倒野怪。連線時由伺服器計算，獎勵也由伺服器發。
- 主線的獎勵要回野外營地找指定的人領；每週和支線在任務頁直接領。
- 單人副本的打斷和踩圈次數是手機回報的數字，伺服器只限制上限。
- 任務定義在 `sim.js` 的 `MAIN`、`WEEK`、`SIDE`，加新任務只要加一筆。

## 好友

- 一起打過線上副本的人會進「最近隊友」，結算畫面可以直接加好友。
- 加好友是申請制：雙方都加了對方才算好友，才看得到對方在不在線上，也才能邀請。
- 邀請連結：有房號的房間會顯示一條連結（網址加 `?room=房號`），朋友點開就會帶到同一個房間。
- 打完之後「原隊再來一場」會把同一批人帶到同一個房間。

## 部署

伺服器是一個普通的 Node 程式，網頁和 WebSocket 都由它提供，讀 `PORT` 環境變數。
repo 根目錄的 `render.yaml` 是給 Render 用的設定，還沒有實際部署驗證過。

只開 `index.html`（例如放在靜態空間）時沒有伺服器，會自動只顯示單人模式。
靜態頁面要連到別處的伺服器，可以在網址加 `?server=wss://你的主機/ws`。
