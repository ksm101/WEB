# 燼潮 Embertide

直立手機的三分鐘四人副本。可以單人玩（AI 隊友），也可以連線和其他玩家一起打。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 用戶端：畫面、操作、連線 |
| `sim.js` | 戰鬥運算，瀏覽器（單人）和伺服器（連線）共用同一份 |
| `server.js` | 連線伺服器：提供網頁、帳號、好友、房間配對、在伺服器上跑副本 |
| `story.js` | 劇情內容：序章、每個主線任務各一段短對話、營地角色的閒聊 |
| `store.js` | 帳號存檔：記憶體加一個 JSON 檔，另外可以打包成有簽章的備份 |
| `test/online.test.js` | 用模擬玩家測伺服器 |

## 在自己電腦上跑

需要 Node 18 以上。

```
cd game
npm install
npm start        # http://localhost:8080
npm test
```

同一個 Wi-Fi 下的手機開 `http://<電腦的區網 IP>:8080` 就能一起玩。

## 連線怎麼運作

- 副本在伺服器上算，用戶端只送操作（移動、放技能），伺服器每秒回傳 15 次畫面狀態。
- 自己的角色移動會先在本機顯示，再向伺服器的位置靠攏，所以拖曳不會有延遲感。
- 留空房號是隨機配對：8 秒內湊到的人一起出發，空位由 AI 補上。
- 輸入房號是和朋友開房：在場的人都按開始，或四人到齊就出發。
- 斷線時 AI 會接手你的角色；重新連上（包含重新整理頁面）會回到原本的位置。

## 角色

- 遊戲開啟後先到選角畫面；沒有角色時直接進創角畫面。創角要選職業、取名字（最多 8 個字）。
- 一個帳號最多 4 個角色。職業在創角時決定，之後不能改。
- 每個角色有自己的等級、經驗、塔的層數、裝備、背包、任務進度和技能配置。好友名單屬於帳號，所有角色共用。
- 別人看到的名字是你目前使用的角色名。
- 連線時角色存在伺服器；在房間或副本裡不能換角色。進副本的職業一律以角色為準，不看手機送來的資料。
- 刪除角色要按兩次確認，刪掉無法復原。
- 舊版（沒有角色的時候）的存檔會自動變成一個角色。

## 帳號和存檔

- 第一次連線時伺服器發一個帳號（之後在帳號底下創角色），登入用的金鑰存在這台裝置的瀏覽器裡。目前沒有綁定信箱，清掉瀏覽器資料或換裝置就是新帳號。
- 層數、裝備、通關紀錄、好友名單都存在伺服器。線上副本的掉寶和升層由伺服器決定。
- 單人副本在手機上運算，結束時回報伺服器。伺服器無法重演那一場，只檢查合不合理（層數不超過帳號層數、花的實際時間夠長）。
- 存檔寫在 `DATA_DIR`（預設 `game/data/`）。主機的硬碟如果不保留（免費方案常見），伺服器重啟後檔案會消失：
  這時裝置會交出伺服器簽過章的備份，伺服器驗章後還原。簽章用的 `EMBERTIDE_SECRET` 必須固定，換掉後舊備份全部失效。
- 備份只在本人上線時還原。硬碟不保留的主機重啟後，還沒上線的人不會出現在別人的好友狀態裡，要等他們回來。

## 背包和製作

- 副本掉三種材料：鏽鐵屑、鹽晶、沉鐘碎片。三分鐘內通關一定有沉鐘碎片，滅團也會拿到少量鏽鐵屑。
- 鍛造：直接做一件指定部位的裝備，裝等是該層的中上水準。
- 淬鍊：把身上某個部位的裝等加 2，上限跟著帳號層數走。
- 潮息藥水：副本中回復 35% 血量，每場限用 1 瓶，最多帶 5 瓶。
- 規則寫在 `sim.js`，伺服器和離線版用同一份。連線時背包以伺服器為準，製作由伺服器執行。

## 技能和瞄準

- 每個職業有 6 個一般技能和 2 個大招，一次帶 3 個一般技能加 1 個大招。起始的 4 個以外，其餘在 3、5、8、10 級解鎖。資料在 `sim.js` 的 `SKILLS` 和 `CLASSES`。
- 換技能在主選單的「換技能」。連線時由伺服器保存和檢查（要是該職業的、不重複、已解鎖）；沒有固定哪一格必須是打斷。
- 每個技能有一種瞄準方式：不用瞄準、選敵人、選隊友、選地上的位置、選方向（直線或扇形）。
- 短按技能鍵：自動施放。對敵人的技能會打目前鎖定的目標，沒有就找範圍內最近的；方向技朝目標放；位置技放在目標腳下；隊友技給最需要的人。
- 按住技能鍵拖曳：出現指示（直線、扇形、圓圈，或被選中的人身上的圈），放開就照指的地方施放。拖曳選到的敵人會成為鎖定目標。拖到上方的取消區放開則不施放。
- 瞄準資料跟著施放指令送到伺服器，伺服器只接受格式正確的方向、位置或目標，其餘當作短按處理。
- AI 隊友只會用起始的技能。玩家斷線被 AI 接手時，AI 只用它認得的那幾招。

## 等級

- 角色等級（Lv.1 到 30）靠經驗值升，和塔的層數是兩回事。升級會補滿血，並提高血量和傷害（每級約 6%）。
- 經驗來源：野外擊倒野怪、採集、通關副本（層數越高越多，準時再加兩成五）、領任務獎勵。滅團也有少量經驗。
- 野怪等級會跟著你浮動，但每一群有下限和上限（定義在 `FIELD.packs` 的 `min` 和 `max`）。南邊靠營地的最低，北邊靠塔門的最高，目前整張圖最高到 14 級。
- 野怪比你低 3 級以上，經驗開始遞減，低 7 級以上只剩一成；比你高則略多，最多三成。
- 玩家和野怪用同一條等級強度曲線，所以同等級的戰鬥在任何等級手感都接近，差距來自裝備。
- 副本的敵人和 AI 隊友顯示的是那一層的建議等級（第 N 層是 2N−1 級），副本實際強度仍然照層數計算。
- 連線時經驗由伺服器計算：野怪等級由伺服器依帳號等級和牠所屬的那一群算出來，手機只回報打倒了哪一群的哪一種。

## 野外

- 地圖「鏽灘」：營地在南邊，沉鐘塔的門在北邊，中間有野怪、採集點和岩石。地圖資料在 `sim.js` 的 `FIELD`。
- 一個人去野外時在手機上運算。野怪只會打主動招惹牠或走進牠範圍的人，追太遠會放棄並回原位；營地那一圈牠們不會進來。
- 採集：站在採集點旁邊不動就會自動採，被野怪追的時候不能採。
- 倒下 3 秒後在營火邊醒來，沒有懲罰。離開戰鬥一陣子會自己回血。
- 單人在野外時坦克和治療的傷害有加成，三個職業都打得動。
- 連線時每次採集和擊倒都回報伺服器，由伺服器決定給什麼，並限制速度：同一個點要等它長回來、採集不能比採集時間快、擊倒有固定的速率上限。
- 潮草只有野外有，藥水需要它。
- 營地的四個人可以對話。主線任務完成後要回營地找對應的人領獎，劇情就在世界裡播出來。
- 走到塔門可以直接進副本（單人或線上配對），打完可以選回營地。
- 還沒做：主城。

### 野外事件：漲潮

- 鏽灘上定時出現的公開事件。預設每 6 分鐘一次，每次開放 4 分鐘，地點在兩個位置之間輪流（`FIELD.events`）。
- 開放時地圖和小地圖上會標出範圍和剩餘時間；開始前一分半會先顯示倒數。
- 走進範圍就加入，不用按任何東西、不換畫面：手機會連到伺服器上這一次漲潮的共用場地，你出現在你走進來的位置。其他走進來的玩家（包含陌生人）都在同一個場地，最多 8 人。
- 內容是三波：螃蟹、螃蟹加學徒、精英「鏽錨巨蟹」（會砸地，有紅圈預警）。怪物數量和血量看當下在場人數，等級跟在場者的平均等級（限制在 3 到 16 級之間）。
- 事件中倒下會在事件邊緣站起來，不會被送回營地。
- 打完三波，在場的每個人都拿到經驗和材料（含一個沉鐘碎片）；時間到沒打完就什麼都沒有。
- 結束後會列出一起打的人，他們會出現在好友頁的「最近隊友」，可以加好友。這是野外認識陌生人的途徑。
- 走出範圍太遠會離開事件，回到你原本的野外（自己的或隊伍的），站在原地。
- 從隊伍的野外走進去時，是你一個人過去；隊友要各自走進來。
- 需要伺服器：沒有伺服器的版本不會出現事件。排程用伺服器的時鐘，`eventPeriod` 和 `eventDur` 可以在啟動時調整。

### 組隊野外

- 用房號組成隊伍一起去野外，最多 4 人，職業不限。野外裡只有同隊伍的人，沒有陌生人。
- 組隊的野外由伺服器運算，和副本用同一套連線方式；隨時可以用房號走進去或離開，不用等人、沒有準備畫面。
- 進入方式：主頁填房號後按「和隊伍去野外」，或從好友名單按「去野外」（會開一個新隊伍並邀請對方）。
- 野怪等級跟著隊伍的平均等級（仍在每一群的上下限內），血量隨人數增加，攻擊力不變。
- 採集點每個人各採各的：你採過的點只對你消失，隊友還看得到。
- 打倒野怪時，附近的隊友每個人都拿到經驗和掉落，各自計算。
- 一個人打野外時坦克和治療的傷害加成，在組隊時不適用。
- 走到塔門可以選「和隊伍一起進塔」：會用同一組房號開副本房間，其他還在野外的隊友會收到通知。副本有職業位置限制（一坦、一補、兩輸出），撞職業的人進不去。
- 斷線重連後會自動走回隊伍的野外。

## 任務

- 主線：一次一個、照順序，目前 8 個，帶玩家走過通關、打斷、製作、準時、淬鍊和爬層。
- 每週：四個（其中「撐過 2 次漲潮」需要伺服器），每週一 00:00（台北時間）重置。
- 支線：做一次就結束，順序不限，其中兩個在野外完成（採集、擊倒野怪）。需要其他玩家的支線在離線版不會出現。
- 進度在這幾種時候前進：打完一場副本、製作成功、互加好友、野外採集、野外擊倒野怪。連線時由伺服器計算，獎勵也由伺服器發。
- 主線的獎勵要回野外營地找指定的人領；每週和支線在任務頁直接領。
- 單人副本的打斷和踩圈次數是手機回報的數字，伺服器只限制上限。
- 任務定義在 `sim.js` 的 `MAIN`、`WEEK`、`SIDE`，加新任務只要加一筆。

## 好友

- 一起打過線上副本的人會進「最近隊友」，結算畫面可以直接加好友。
- 加好友是申請制：雙方都加了對方才算好友，才看得到對方在不在線上，也才能邀請。
- 邀請連結：有房號的房間會顯示一條連結（網址加 `?room=房號`），朋友點開就會帶到同一個房間。
- 打完之後「原隊再來一場」會把同一批人帶到同一個房間。

## 部署

伺服器是一個普通的 Node 程式，網頁和 WebSocket 都由它提供，讀 `PORT` 環境變數。
repo 根目錄的 `render.yaml` 是給 Render 用的設定，還沒有實際部署驗證過。

只開 `index.html`（例如放在靜態空間）時沒有伺服器，會自動只顯示單人模式。
靜態頁面要連到別處的伺服器，可以在網址加 `?server=wss://你的主機/ws`。
