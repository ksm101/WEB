# 燼潮 Embertide

直立手機的三分鐘四人副本。可以單人玩（AI 隊友），也可以連線和其他玩家一起打。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 用戶端：畫面、操作、連線 |
| `sim.js` | 戰鬥運算，瀏覽器（單人）和伺服器（連線）共用同一份 |
| `server.js` | 連線伺服器：提供網頁、帳號、好友、房間配對、在伺服器上跑副本 |
| `story.js` | 劇情內容：序章、每個主線任務各一段短對話、營地角色的閒聊 |
| `store.js` | 帳號存檔：記憶體加一個 JSON 檔，另外可以打包成有簽章的備份 |
| `test/online.test.js` | 用模擬玩家測伺服器 |

## 在自己電腦上跑

需要 Node 18 以上。

```
cd game
npm install
npm start        # http://localhost:8080
npm test
```

同一個 Wi-Fi 下的手機開 `http://<電腦的區網 IP>:8080` 就能一起玩。

## 連線怎麼運作

- 副本在伺服器上算，用戶端只送操作（移動、放技能），伺服器每秒回傳 15 次畫面狀態。
- 自己的角色移動會先在本機顯示，再向伺服器的位置靠攏，所以拖曳不會有延遲感。
- 留空房號是隨機配對：8 秒內湊到的人一起出發，空位由 AI 補上。
- 輸入房號是和朋友開房：在場的人都按開始，或四人到齊就出發。
- 斷線時 AI 會接手你的角色；重新連上（包含重新整理頁面）會回到原本的位置。

## 帳號和存檔

- 第一次連線時伺服器發一個帳號，登入用的金鑰存在這台裝置的瀏覽器裡。目前沒有綁定信箱，清掉瀏覽器資料或換裝置就是新帳號。
- 層數、裝備、通關紀錄、好友名單都存在伺服器。線上副本的掉寶和升層由伺服器決定。
- 單人副本在手機上運算，結束時回報伺服器。伺服器無法重演那一場，只檢查合不合理（層數不超過帳號層數、花的實際時間夠長）。
- 存檔寫在 `DATA_DIR`（預設 `game/data/`）。主機的硬碟如果不保留（免費方案常見），伺服器重啟後檔案會消失：
  這時裝置會交出伺服器簽過章的備份，伺服器驗章後還原。簽章用的 `EMBERTIDE_SECRET` 必須固定，換掉後舊備份全部失效。
- 備份只在本人上線時還原。硬碟不保留的主機重啟後，還沒上線的人不會出現在別人的好友狀態裡，要等他們回來。

## 背包和製作

- 副本掉三種材料：鏽鐵屑、鹽晶、沉鐘碎片。三分鐘內通關一定有沉鐘碎片，滅團也會拿到少量鏽鐵屑。
- 鍛造：直接做一件指定部位的裝備，裝等是該層的中上水準。
- 淬鍊：把身上某個部位的裝等加 2，上限跟著帳號層數走。
- 潮息藥水：副本中回復 35% 血量，每場限用 1 瓶，最多帶 5 瓶。
- 規則寫在 `sim.js`，伺服器和離線版用同一份。連線時背包以伺服器為準，製作由伺服器執行。

## 野外

- 地圖「鏽灘」：營地在南邊，沉鐘塔的門在北邊，中間有野怪、採集點和岩石。地圖資料在 `sim.js` 的 `FIELD`。
- 野外目前是單人的，在手機上運算。野怪只會打主動招惹牠或走進牠範圍的人，追太遠會放棄並回原位；營地那一圈牠們不會進來。
- 採集：站在採集點旁邊不動就會自動採，被野怪追的時候不能採。
- 倒下 3 秒後在營火邊醒來，沒有懲罰。離開戰鬥一陣子會自己回血。
- 單人在野外時坦克和治療的傷害有加成，三個職業都打得動。
- 連線時每次採集和擊倒都回報伺服器，由伺服器決定給什麼，並限制速度：同一個點要等它長回來、採集不能比採集時間快、擊倒有固定的速率上限。
- 潮草只有野外有，藥水需要它。
- 營地的四個人可以對話。主線任務完成後要回營地找對應的人領獎，劇情就在世界裡播出來。
- 走到塔門可以直接進副本（單人或線上配對），打完可以選回營地。
- 還沒做：組隊野外（由伺服器運算、看得到隊友）、野外事件、主城。

## 任務

- 主線：一次一個、照順序，目前 8 個，帶玩家走過通關、打斷、製作、準時、淬鍊和爬層。
- 每週：三個，每週一 00:00（台北時間）重置。
- 支線：做一次就結束，順序不限，其中兩個在野外完成（採集、擊倒野怪）。需要其他玩家的支線在離線版不會出現。
- 進度在這幾種時候前進：打完一場副本、製作成功、互加好友、野外採集、野外擊倒野怪。連線時由伺服器計算，獎勵也由伺服器發。
- 主線的獎勵要回野外營地找指定的人領；每週和支線在任務頁直接領。
- 單人副本的打斷和踩圈次數是手機回報的數字，伺服器只限制上限。
- 任務定義在 `sim.js` 的 `MAIN`、`WEEK`、`SIDE`，加新任務只要加一筆。

## 好友

- 一起打過線上副本的人會進「最近隊友」，結算畫面可以直接加好友。
- 加好友是申請制：雙方都加了對方才算好友，才看得到對方在不在線上，也才能邀請。
- 邀請連結：有房號的房間會顯示一條連結（網址加 `?room=房號`），朋友點開就會帶到同一個房間。
- 打完之後「原隊再來一場」會把同一批人帶到同一個房間。

## 部署

伺服器是一個普通的 Node 程式，網頁和 WebSocket 都由它提供，讀 `PORT` 環境變數。
repo 根目錄的 `render.yaml` 是給 Render 用的設定，還沒有實際部署驗證過。

只開 `index.html`（例如放在靜態空間）時沒有伺服器，會自動只顯示單人模式。
靜態頁面要連到別處的伺服器，可以在網址加 `?server=wss://你的主機/ws`。
