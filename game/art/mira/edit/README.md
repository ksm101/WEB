# 手修用的底稿（Aseprite）

這兩張是蜜拉的一般立繪 `portrait.png` 的複本，沒有陰影。只改眼睛，其他一格都不要動。

- `darkgrin_base.png`：閉眼笑。把兩隻眼睛（眼白、虹膜、下眼線、睫毛）塗成旁邊的膚色，再用她原本上睫毛的顏色畫兩條往上拱的弧線（^ ^），外眼角留一點睫毛尾巴。
- `darkside_base.png`：看旁邊。眼睛的外形和睫毛完全不動，只把虹膜（連瞳孔和高光）整塊往旁邊移幾格，空出來的地方補眼白的顏色，移出眼眶的部分剪掉。

做法：鉛筆工具打開 Pixel-perfect、Alt 吸她原本的顏色、存成同樣的檔名（192 × 256、透明背景、不要縮放）。存好推上分支後，雲端會用 `tools/mira-shadow.py` 蓋陰影、做披肩版、檢查後登記進遊戲。

遊戲不會讀這個資料夾。
